# Android 工具箱

## 1.52.0：新增五个离线工具

入口为「守卫 → 功能 → 工具箱」。原有计时器、抽签、文本工具保留，新增：

| 工具 | 操作 |
| --- | --- |
| 科学计算器 | 表达式、括号、幂、百分比、sin/cos/tan、反三角函数、sqrt/log/ln/abs、pi/e；角度与弧度切换；保存最近 20 条计算历史 |
| 工科单位换算 | 长度、面积、体积、质量、时间、速度、压力、功率、能量、温度；交换单位；温度不允许低于绝对零度 |
| 日期计算 | 日期选择器或手输 YYYY-MM-DD；日期差及起始日期加减天数；日期差不含起始日，同日为零 |
| PDF 合并与提取 | 添加 2–20 个文件后调整顺序合并；提取时只选 1 个文件并填写 `1,3-5` 等页码范围，留空为全部；另存新 PDF，保留文字层 |
| 图片处理 | 最长边 64–4096 像素、等比例缩小；JPEG/PNG/WebP 转换；JPEG/WebP 质量 1–100；纠正 EXIF 朝向，JPEG 的透明区域填白 |

PDF 单文件最多 40 MB、总计 80 MB、500 页，不支持加密 PDF。图片输入最多 40 MB，PNG 无损编码不使用质量参数。处理任务在后台线程运行，输入来自系统文件选择器，输出通过系统另存选择器保存；不覆盖源文件，不新增权限，不上传文件。不能承诺压缩后一定比原文件小，完成后会显示结果大小。

实现：`ToolkitActivity` 负责交互及文件选择器；`ToolMath` 提供纯计算；`ToolFiles` 负责 PDF 和图片处理。旧的工具箱和备忘录存储不迁移。PDF 使用 PdfBox-Android 2.0.27.0；来源、校验值、许可和依赖范围见 `dpc/libs/README.md`。

验证：新增 `ToolMathTest` 80 项通过，原有本地回归通过。手机生成样例 PDF 的页数、顺序、提取内容、文字层与三种图片尺寸/透明处理已通过；使用独立临时文件，结束后清理。完整 UI 验收结果见本轮交接记录，不将组件验证等同系统文件选择器全流程验收。

三个工具全部在本机运行，不联网、不加通知/闹钟/前台服务，不新增权限。

| 工具 | 用法 |
| --- | --- |
| 计时器 | 倒计时（1/5/10/25/45/60 分钟预设）或正计时；开始/暂停、重置；倒计时到 0 只在页面上显示「时间到」，不响铃不通知。离开页面即停表 |
| 随机抽签 | 一行一个选项，点「抽一个」；选项会去重、去空行，最多 200 个、单个最多 60 字；抽签过程有短暂闪烁动画，结果下显示共几个选项；选项会保存在本机，下次打开还在 |
| 文本工具 | 粘贴文本后实时显示字数（不含空白）和非空行数；可一键转大写、转小写、按行去重、按行排序。上限 2 万字符 |

## 实现

| 文件 | 说明 |
| --- | --- |
| `dpc/java/com/afs/guard/Toolbox.java` | 纯逻辑：`clock`/`remain` 计时格式、`splitItems`/`pickIndex` 抽签、`charCount`/`lineCount`/`upper`/`lower`/`dedupeLines`/`sortLines` 文本整理；抽签选项存 `afs_guard` / `toolbox_items` |
| `dpc/java/com/afs/guard/ToolboxActivity.java` | 工具箱首页 + 三个工具页（同一个 Activity，Intent extra `tool` 区分），全部走 `Ui` 主题色，深浅色 / 纯黑 / 高德风格自动跟随 |
| `dpc/test/java/com/afs/guard/ToolboxTest.java` | 52 项离线断言：时钟边界、剩余时间夹取、选项拆分/去重/截断/上限、抽签下标范围、字数与行数、大小写、按行去重与排序、`null` 输入 |

计时器用页面内的 `Handler`，`onPause`/`onDestroy` 会移除回调，不常驻后台；抽签和文本工具不需要任何权限。
