# 1.78.1 本地优化批次 · 2026-11-02

本轮只进行源码优化、离线回归和构建，按用户要求暂不做真机复现、ADB操作或安装。工作基于1.78.0，未做页面结构重构，未提交Git。

## 改动

- DayBoundary保存待生效小时与当前额度日结束时间；重复修改保持同一个生效点，选回当前小时取消待生效修改。当前额度日内继续使用原日界，避免切换配置导致当天用量被清空。冻结页选择器显示待生效选项并明确提示延后生效。DailyQuotaStore快照增加生效小时作为缓存失效条件。
- 旧额度迁移对账本做深拷贝，在新配置成功落盘后仅清理成功迁移的旧项目。失败、冲突项继续保留；原始备份不再受到迁移中内存修改污染，旧表清理提交失败明确抛错。无时段规则的旧应用按全天统计，避免空规则异常。
- 久用锁的UI线程读取不可变前台采样结果；系统使用事件查询改由单独后台线程执行，合并在途采样，过旧结果不参与判断。仅改LockEnforcer消费路径，未将所有系统事件查询改成增量，也未声称减少整机耗电。
- Guard的异步请求合并由同一把请求锁管理，消除检查pending到退出之间漏请求的窗口。同步及异步apply共用整轮执行锁，避免不同工作线程交错提交冻结状态；所有业务判断在获得执行锁后重新计算。
