# Android 主题设置

1.46.0（2129），2026-10-25。入口：底栏「守卫」→右上角「主题设置」。对照手机安装的 FlClash 0.9.1 主题页，提供其 Android 页面中的全部设置项，并新增可切换的[高德风格](AMAP-STYLE.md)。

| 设置 | 功能 |
| --- | --- |
| 界面风格 | 原有风格、高德风格，支持预览和随时切换 |
| 实时预览 | 顶部手机预览随设置变化，点击预览底栏可以体验滑动或淡入 |
| 主题模式 | 自动跟随系统、浅色、深色 |
| 纯黑模式 | 标准、纯黑；深色时生效 |
| 颜色 | 跟随系统、8 种默认色、新增自定义色；长按颜色编辑或删除；重置前确认 |
| 配色风格 | 鲜明、氛围、柔和、单色 |
| 颜色编辑器 | 网格、光谱、HSV 滑块、六位 HEX；浅色和深色预览；确认才保存 |
| 底栏 | 悬浮、固定；固定采用实色全宽底栏 |
| 选项卡动画 | 滑动、淡入，作用于应用实际页面 |
| 液态玻璃 | 无、标准、极致，切换实际绘制路径 |
| 字体 | 默认、两款内置中文字体、手机已安装的字体；支持名称搜索和逐项预览 |
| 文本缩放 | 跟随系统，或 80%–140% 自定义，每档 5%；可恢复 100% |

主题设置会保存并应用到打卡、记忆、守卫、刷题、冻结及其子页面。自定义文字大小只调整本应用；不会更改手机的系统文字大小。打卡卡片原有的独立字体和背景设置继续优先生效。

删除颜色、重置配色均有确认；取消颜色编辑不写入设置。配色重置只恢复默认颜色列表、默认主题色与鲜明风格，不清除字体、动画、文字大小等其他选择。

## 实现和兼容

主题参数保存在现有 `afs_ui` 偏好中的 `appearance_v1`，保留旧版 `theme` 键兼容；`appearance_revision` 用于刷新已经打开的页面。全局文字缩放通过 Activity 的配置上下文实现。没有变更冻结规则、学习数据或打卡记录。

动态主题色在 Android 12 及以上读取系统色，旧系统回退到默认蓝色。玻璃的完整 GPU 光学路径要求 Android 13 及以上；旧系统保留兼容绘制。当前实机验收设备为 Android 16，未将其他机型列为已验证。

配色使用 Google Material Color Utilities 的 HCT 算法，源码、Apache-2.0 许可证及校验值位于 `dpc/java/vendor/materialcolor/`，APK 内包含许可证。主题页、预览和底栏采用本项目的原生 Android 实现，不宣称与 Flutter 页面逐像素一致。

- 手动完成自定义颜色新增、编辑、取消、删除、重置；字体搜索、选择和恢复默认；自定义文字 140%、恢复 100%、跟随系统 115% 的操作。测试颜色已清理，字体恢复默认，文字大小恢复跟随系统。
- 最终构建和离线结果：`.codex-fix/theme-replica/build-release.log`、`tests-final.log`；设备结果：`device-first.log`。

构建：在 `dpc/` 运行 `bash build.sh`。离线检查：`bash test/run.sh`。设备检查：构建后运行 `test/run-appearance-device.ps1 -Serial <设备序列号> -Python <Python路径>`，会临时安装本项目签名的测试包并在结束后卸载。
