## 1.53.1：按手机便签交互补齐待办清单

- 「待办」将当前段落或选中段落转为可点击的圆形清单；对全为待办的选区再次点击，可移除勾选框。混合选区保留已有完成状态。
- 点圆圈完成／恢复，完成项变灰，保持原先顺序。正文与待办可以混排；续行对齐到文本，编辑中不显示 Markdown 标记。

## 1.51.0：基于 Markor 组件改造

备忘录仍从「守卫／设置 → 功能 → 备忘录」进入，原有 `afs_guard/memos_v1` 数据直接沿用，不迁移、不删除；回收站使用独立的 `memos_trash_v1`。

### 开源项目选择

比较了 [Notepad](https://github.com/farmerbb/Notepad)、[Notally](https://github.com/OmGodse/Notally) 和 [Markor](https://github.com/gsantner/markor)。选择 Markor 的离线文本编辑方向，抽取实际可复用的原生 TextView Markdown 解析组件；没有把整个应用或其依赖搬入项目。

- Markor 应用：Apache-2.0。
- 实际采用文件：`app/src/main/java/net/gsantner/opoc/format/GsSimpleMarkdownParser.java`。
- 文件独立许可：`Unlicense OR CC0-1.0`，本项目按 Unlicense 分发。
- 上游 Git blob SHA-1：`032a5e780412f26c38e03887fb9b5e1ad5f492c7`，取得日期 2026-10-26。
- 修改：Java 包名调整；应用侧包装 HTML 转义、深浅色标题颜色和清单符号。
- 原作者署名保留在源码，完整许可随 APK 放入 `assets/licenses/markor-memo.txt`。页面「开源说明」提供来源。
- 撤销重做、文件选择器、回收站与现有存储的整合是本项目实现，不宣称它们直接复制自 Markor。

### 功能

| 功能 | 行为 |
| --- | --- |
| 编辑、搜索、置顶 | 保留原来的操作，列表按置顶优先、更新时间倒序排列 |
| 撤销／重做 | 同时记录标题和正文，输入停顿后分组；最多 40 个快照，退出或重建编辑页后重置历史 |
| 快捷格式 | 标题、粗体、Markdown 清单；对当前选区或所在行操作 |
| 预览 | 原生 TextView 显示基础标题、粗体、斜体、列表；HTML 原文转义，不执行脚本、不联网加载图片；不是完整 CommonMark 渲染器 |
| 导入 | 系统文件选择器选择 UTF-8 文本／Markdown，先进入可编辑草稿，不直接覆盖任何旧记录；超过 2 万字符或错误编码会提示 |
| 导出 | 当前标题和正文导出为 `.md`，由用户选择位置；这是单条文本导出，不包含置顶、id、回收站等完整备份元数据 |
| 回收站 | 删除确认后移入回收站，保留 id、内容、时间和置顶状态；可恢复，永久删除需再次确认 |
| 容量保护 | 活跃和回收站各最多 500 条。满容量拒绝新增／恢复，保留现有内容，不再自动淘汰旧记录 |

点「完成」或返回时保存。仍不支持跨应用同步或后台自动保存；转屏保存当前草稿。标题最多 80 字符，正文最多 20,000 字符。不新增权限、不改冻结规则和学习数据。
