# 本地数据、备份与云端配置

入口：主页 **数据与备份**，或打卡页的 **同步** 按钮。

学习记录继续存放在应用私有目录，不需要服务器。此版本新增统一备份和配置入口；WebDAV、GitHub 私有仓库、Git 仅保存配置，尚不执行上传、下载或自动同步。原有 Gist 同步独立保留，名称明确标为旧版功能。

## 完整本地备份

点“导出完整本地备份”，通过系统文件选择器保存 ZIP。包含本机目标与打卡台账、记忆与图片、题库和答题记录、目标/禁忌/奖励卡片与周期记录、笔记与回收站/分类/附件、冻结规则与时间格、学习时段和抽签选项。

备份不包含云端配置及其凭据、AI 服务密钥、设备管理授权、首次宽限计时或固定冻结时区。备份中的笔记等用户正文按原样保存，不对正文内容做密码识别或删改。ZIP 未加密，应保存在自己的安全位置。主题等界面偏好暂不在完整备份范围。

文件包含版本清单、每项大小和 SHA-256。导入拒绝越界路径、重复项、未列入许可清单的文件、不匹配的校验值或不支持的格式版本。大小上限根据当前设备的应用堆上限预留安全预算计算，页面显示实际限制，最大为解压后 128MB；超过限制会停止，可改用各模块的备份工具。

## 完整恢复

恢复是覆盖操作，会先预览并要求确认。它只允许在未启用设备所有者，或首次配置宽限期内进行，以免通过回放旧备份重置学习、奖励或冻结状态。日常增加内容请使用下方的记忆卡片、题库、笔记导入入口；各模块现有的导入/合并行为不变。

确认恢复后，先把经过校验的备份存入应用私有目录，再重启应用，在学习存储和后台服务初始化前应用恢复。写入前保存原数据回滚包并记录事务标记；写入失败或进程中断会恢复原数据。不会恢复或清除当前设备管理身份，也不会重置首次宽限计时。

恢复完成后保留本机已有云端凭据，但暂停旧版 Gist 同步并切换合并缓存空间，防止恢复后的本地内容自动推向原云端。需要继续 Gist 同步时重新验证并启用。新云端配置入口仍只保存配置。

## 云端配置字段

| 类型 | 地址或目标 | 其他字段 | 凭据 |
|---|---|---|---|
| WebDAV | HTTPS 服务器地址 | 相对目录、用户名 | 应用密码或 token |
| GitHub 私有仓库 | `owner/private-repository` | 分支、相对目录、用户名 | GitHub 访问令牌 |
| Git | HTTPS / SSH / `git@host:path` 仓库地址 | 分支、相对目录、用户名 | HTTP 密码或 token；SSH 密钥接入在传输阶段处理 |

配置可保存和删除。保存不验证服务器连通性、仓库私有性或访问权限，也不标记为已连接；这些检查属于后续传输实现。新配置入口的云端凭据使用 Android Keystore 的 AES-GCM 加密，编辑时留空保留已存凭据，不在界面回显明文。
