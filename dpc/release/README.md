# AwayFromShorts Android：Windows 部署包

版本、APK 哈希与维护包信息以同目录 manifest.json 为准。本地生成的构建不等于已经上传 GitHub 发行。

支持 Android 7.0（API 24）及以上。应用冻结使用设备所有者的系统暂停能力，不需要 Root。包内包含 ADB、安装向导、主 APK 和同签名维护 APK；无需额外安装 Java、Python、Git 或 Android Studio。

## 安装和升级

1. 完整解压 ZIP。手机开启 USB 调试，连接后在手机上允许电脑调试。
2. 双击“开始安装.cmd”，按型号和序列号选择设备，先点“检查设备”。
3. 首次部署先阅读本页恢复说明，了解限制强停、卸载、安全模式、改系统时间及系统内恢复出厂的管理行为，勾选确认后安装。
4. 已有同签名授权时直接点安装，按保留数据升级处理，不重复配置管理者。签名不兼容时停止，不卸载原应用。
5. 成功后到手机“守卫 → 部署与权限检查”完成使用情况等所需权限；在冻结页安排应用和额度。

工具会检查账号、分身、多用户及其他管理者。条件不满足会停止并显示原因，不自动清机、删账号或删用户。部分机型需要驱动或额外开启 USB 安装；个人资料如何处理必须由你自行备份并决定。

运行中请等待检查／安装结束再关闭。错误和运行输出可点“保存诊断日志”，日志只保存在你选择的位置。

## 恢复管理

包内“恢复管理.cmd”通过同签名维护 APK 解除设备管理和冻结。先备份需要的数据，再按工具提示输入 RECOVER。默认保留数据；明确选择卸载才删除应用数据。维护包高一个版本号，用过后重新使用应选择版本号更高的同签名主包。

不要用 remove-active-admin 或卸载来猜测正式安装是否可以解除。使用随包匹配的恢复工具，并核对系统确认结果。

## 命令行

原命令行参数继续支持：

    powershell -NoProfile -ExecutionPolicy Bypass -File deploy.ps1 -Serial 设备序列号 -CheckOnly
    powershell -NoProfile -ExecutionPolicy Bypass -File deploy.ps1 -Serial 设备序列号 -NonInteractive -AcceptDeviceOwner

仅检查不会修改设备。首次无人值守部署必须显式确认管理授权。应用源代码和第三方许可证随独立源码包提供，项目采用 MIT 许可证。
