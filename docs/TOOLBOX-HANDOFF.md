# 工具箱 1.52.0 交接

用户选择的范围：科学计算器、工科单位换算、日期计算、PDF 合并/提取、图片处理。原有三工具保留。本轮没有继续扩展备忘录或修改冻结/学习逻辑。

## 改动

- `ToolkitActivity.java`：新增五页、主题色、计算历史、系统文件选择器/另存、PDF 文件顺序调整、后台任务与转屏状态。
- `ToolMath.java`：有界表达式解析器、十类单位换算、日期和 PDF 页码校验。
- `ToolFiles.java`：PDFBox 合并/提取与 Bitmap 压缩/缩放/EXIF 朝向处理；不写源文件。
- `ToolboxActivity.java`、`MainActivity.java`、`AndroidManifest.xml`：入口、说明、内部 Activity 注册。
- `build.sh`、`test/run.sh`：PDFBox 编译/dex 依赖，Windows/Linux classpath 分隔处理；版本 1.52.0 / 2158。
- `libs/README.md`、PDFBox JAR、assets：原始依赖、校验值、资源及完整许可证。
- `ToolMathTest.java`、`ToolkitDeviceTest.java`、`run-toolkit-device.ps1`：纯逻辑及实机回归。

## 限制与后续

- 不支持加密 PDF；不是 PDF 内容编辑器。提取将选定页保存为一个新 PDF，不批量生成逐页文件。
- 文件选择器的不同云提供方、另存失败/进程终止场景、所有 OEM 深浅色/大字号组合尚未逐一实机覆盖。
- 图片转换不承诺体积一定减少；不复制 EXIF 元数据，按朝向显示后输出像素。
- 表达式最长 512 字符、递归深度 64，数值显示约 12 位有效数字；百分比为除以 100，不模拟商业计算器的加法百分比特例。
- 日期差采用 UTC 日历天计算，不包含起始日；适合现代日历日期。
- 工作区原有多处其他任务的未提交改动，本轮未提交或推送 Git，未回退它们。
