# 刷题

入口：底栏 → 刷题。可通过“＋ 科目”添加电路、材料力学、信号与系统等科目；导入题目里的新科目会自动出现在科目栏。高数、线代各有 12 道原创入门示例，适合检查公式与操作，完整题库请自行导入。

- 按科目、章节顺序练习，随机练习或只练未做题。
- 单选、多选、判断自动判分。填空、计算、证明题展示参考答案与解析后自行核对，不把数学表达式作字符串判分。
- 答错进入错题本，重新答对后从待复习列表移出，原答题记录保留；支持收藏与搜索。
- 本日、本月、累计作答题次和正确率。每次提交计一次，重复点击、旋转和恢复页面不重复计数。自行判断的题也纳入正确率。
- 练习队列、当前选项、解题思路、展开答案和提交状态保存在本机；未提交不计入完成数。
- 数据独立保存在私有 `quiz-v1.json`，原子写入，与冻结规则及打卡数据分开。目前不联动学习闸门，不做云同步。

## 导入

点击“导入题库”选择文件或粘贴文字，先校验全部内容，再显示新增数量、重复数量和前三题预览，确认后才写入。任一错误不产生部分导入。相同内容跳过；同 id 对应不同内容时拒绝，防止串用答题进度。

UTF-8 JSON：顶层可为题目数组，也可为 `{ "name":"题库名", "subject":"高数", "questions":[...] }`。题目 `subject` 优先于题库科目，缺省时采用导入时所选科目。

```json
{
  "name": "高数第一章",
  "subject": "高数",
  "questions": [
    {
      "id": "calc-limit-001",
      "chapter": "极限与连续",
      "type": "single",
      "stem": "求 $\\lim_{x\\to0} \\sin x/x$。",
      "options": ["$0$", "$1$", "$-1$", "不存在"],
      "answer": "B",
      "analysis": "这是基本重要极限。",
      "source": "自编题"
    }
  ]
}
```

- 必填 `stem` 和 `answer`。`id` 可省略，省略时按内容生成稳定 id。
- `subject`：自定义科目名称，1–40 字、不能包含换行；高等数学 / 线性代数仍分别归一为高数 / 线代。
- `type`：`single` 单选、`multiple` 多选、`judge` 判断、`short` 填空、`solution` 解答（默认）。支持对应中文题型名。
- 选择题 2–8 个选项，`options` 为文字数组或连续的 A/B/C 对象；答案为 `B`、`AC` 或 `["A","C"]`。多选必须完全匹配。
- 判断题答案用 A/B（正确/错误），也接受“正确”/“错误”。填空和解答题的答案为文字，可含公式。
- `analysis` 为解析，也接受 `explanation`；`chapter`、`source`、`bank` 可选。
- CSV 表头为 `subject,chapter,type,stem,A,B,C,D,answer,analysis,source`，也接受“科目,章节,题型,题干,A,B,C,D,答案,解析,来源”。A 开始的选项列连续排列，不用的末尾选项可空置。逗号、双引号、换行遵循标准 CSV 引号转义；支持 CRLF。
- 单次文件最多 4MB，题库总量最多 5000 题，每个文字字段最多 16000 字。
- 公式使用 `$…$`、`$$…$$`、`\(…\)` 或 `\[…\]`。JSON 中反斜杠必须双写；CSV 不需要双写。
- 工具页可导出 JSON 模板或当前全部题目。题库导出**不含答题记录、收藏或未完成练习**，不是完整进度备份。
- PDF、Word、照片、QTI 文件未直接支持，需先整理成上述格式。

## 开源参考和许可

- [学之思 xzs](https://github.com/mindskip/xzs)：参考科目、答题与错题流程，未复制其 AGPL 代码，也不兼容其服务端数据库。
- [text2qti](https://github.com/gpoore/text2qti)：参考题干、选项、答案、反馈分离及数学公式的表达方式，未复制代码，未宣称支持 QTI 导入。
- [KaTeX](https://github.com/KaTeX/KaTeX)，内置 **0.16.22** 的脚本、样式和 woff2 字体，MIT 许可保留在 `dpc/assets/quiz/katex/LICENSE`。安装包内离线运行，不依赖 CDN。

公式 WebView 无 Javascript 原生桥；导入内容经 HTML 转义作为文本，KaTeX `trust:false`，禁用文件、内容访问与网络，拦截仅允许固定的内置 KaTeX 资源路径，外链导航关闭。设置宏展开与尺寸上限。
