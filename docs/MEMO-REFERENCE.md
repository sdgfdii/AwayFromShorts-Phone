## AwayFromShorts 建议顺序

1. 编辑布局：保留当前存储与撤销逻辑，底部横排文字按钮改成紧凑工具栏和展开式格式面板；键盘出现时工具栏保持可达。
2. 补齐基础编辑：可勾选清单、多级标题、列表、文内查找。不能将仅供预览的 Markdown 解析器当作完整富文本编辑器。
3. 分类与外观：笔记本分类、列表/网格切换、笔记背景；新增字段必须兼容现有 `memos_v1`。
4. 图片与扫描另立任务，需要先定义附件存储、备份、删除清理和权限行为。AI、云同步、语音不纳入默认第一批。

以上为分析和改造建议，本轮没有据此修改应用实现或发布新版本。
