# 手机版独立插件

本轮将“屏幕使用统计”迁为独立 APK。其他功能仍在手机宿主中。插件必须独立安装，不会在宿主内下载或执行外部 DEX。

## 使用

1. 首次使用需要升级支持插件的宿主，保留原有包名、官方签名、数据和设备所有者。不要卸载宿主或清除数据。
2. 安装单独交付的屏幕使用统计插件 APK。
3. 在宿主设置的“插件管理”中查看版本、发布者和能力，再手动确认启用。安装后默认停用。
4. 只查看统计需要“读取汇总”能力。系统尚未授予宿主使用情况访问权时，可另授予“前往宿主授权页”，由用户亲自进入系统设置开启。两项能力可以独立撤销。
5. 从打卡历史的“更多”进入统计页面。返回时回到宿主。

同协议、现有能力和官方证书的插件更新只需安装新插件 APK，不必重新安装宿主。新宿主能力或新协议仍需升级宿主。卸载、停用或插件异常不会删除宿主业务数据，也不会解除宿主已经启用的冻结规则。

## 第一版范围

- Android 7.0 / API 24 起，与宿主最低版本相同。
- 仅信任固定的官方发布证书；自签名第三方 APK 不在本版支持范围内。
- 插件用独立 UID 和 Activity 运行。只获得限量的应用名称、时长及趋势汇总，不能通过 API 读取笔记、学习卡、规则、原始使用事件或凭据。
- 插件在得到快照后可以在自己的进程中保存已获得的数据；撤销授权阻止后续读取，不能收回已交付的数据或强制抹掉外部页面。
- 如果设备存储彻底拒绝持久化，宿主会阻断当前进程中的受影响会话并显示保存失败。必须重试并成功保存停用状态，才能保证重启后持久停用；不能把未成功写盘描述为已经永久撤销。
- 冻结判断、罚时、系统执行和已有规则均由宿主决定，统计插件没有阻止或修改这些操作的扩展点。

## 独立构建

宿主沿用 `dpc/build.sh`；插件单独使用 `plugins/usage-stats/build.sh`。两端各自编译 `plugin-api`，插件不依赖宿主实现 JAR，不需要 Gradle 或 AndroidX。

Windows 正式插件可使用 `plugins/usage-stats/build-release.ps1`，指定输出路径及外部签名配置。签名私钥、密码和个人同步凭据不属于仓库或发布包。公开发行不得使用测试信任构建。

## 回退

单独停用插件只移除入口与会话，不会暗中打开旧统计页。需要整体回退迁移时，维护者可用 `AFS_STATS_LEGACY=1` 构建同官方签名、且版本号更高的宿主恢复包，再覆盖安装。保留当前宿主数据和设备所有者；不要通过卸载、清数据或降级实现回退。

具体版本的验收范围、设备记录和尚未通过的门槛见 [PLUGIN-R2-VALIDATION.md](PLUGIN-R2-VALIDATION.md)。
