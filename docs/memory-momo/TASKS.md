## 有效测试要求

1. 原有MemoryTest/MemoryFlashcardsTest/MemorySwipeTest/MemoryStatsTest与全离线回归；实施时采集当前基线，不沿用过时文档断言数量。
2. 预演前后完整MemoryData JSON逐字节相同；预演结果与同一now的真实评分落盘状态一致；rating=1/3、学习/复习/重学、各学科retention/maxInterval、本地零点分别覆盖。不存在就报错，不能创建卡片。
3. 先取消当日计划的fixture场景，读取统计/今日筛选后仍没有plans/session；另确认既有日进度与新卡上限不变。
4. 筛选：lapses=0/1/2/3以上、相同排序值、删除/恢复学科、跨日、空库、超过一页。大量fixture仅模拟器，真实手机不添加卡、评分或奖励。
5. 周/月统计使用当地日历边界，覆盖跨年周、2月29日、夏令时切换；去重卡数与评分次数分开，缺旧字段不回填。稳定性9.99/10/30/60/90边界、学习态与回收站过滤。
6. 页面打开/切换/退出都不新增普通打卡、目标credit或冻结罚时；既有主动学习完成联动单独基线验证，不能把移除原联动作为“独立”的修复。
7. 30000卡fixture的筛选与统计在后台执行，离页结果不触UI；列表只创建可见页，图片不全库解码。记录实际耗时/内存观察；没测的性能指标不能写成通过。
8. 深浅色、字体放大、减少动态、底栏安全区、返回滚动位置、重复快速切换。新功能不再加独立底栏或大标题。
