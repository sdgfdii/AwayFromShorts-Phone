# 1.78.2 资源优化 · 2026-11-02

## 本批实现

- Backdrop保留原有生成、裁剪和三遍模糊算法，去掉最后的CPU全屏放大副本。ImageView/GPU以滤波放大原1/4宽高纹理。1272×2800的ARGB背景从约13.59MiB降到约0.85MiB（该纹理为1/16），不代表全进程减少16倍，也尚未压低所有中间生成峰值。
- CheckinActivity背景异步加载增加代次校验，避免销毁／重建后旧任务回填；过期未显示位图回收，销毁时解除ImageView引用。已显示位图不强制recycle，避免硬件绘制使用已回收资源。
- 冻结页静态图标缓存按64dp实际像素尺寸栅格化，保留透明、自适应图标绘制结果和过滤显示；Animatable图标保留原实现。缓存按真实Bitmap分配字节计量，键包含密度与深浅色模式，内存压力时清缓存，使用时可重载。其余未使用AppIcons的图标入口本批未改。
- 久用锁后台采样复用现有5秒使用记录缓存，记录实际采样时间和前台是否仍打开，不把缓存误当新采样。额度结算的fresh强制读取保持，不改变配置变动前的结算精度。本批没有实现完整事件增量读取。
- 无新旧额度时不派发额度worker，服务仍按原节拍检查是否启用新额度。保留守护心跳、锁机／提醒节拍、闹钟及唤醒锁；本批未整体重构调度器。
