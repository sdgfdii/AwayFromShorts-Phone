# 记忆卡：三按钮学习模式

## 行为

- 先回忆，再点“显示答案”，最后点“认识／模糊／忘记”。移除 MemoryActivity 对 SwipeCardView、MemorySwipe、卡面点击评分及飞出切卡的调用；共享的滑卡组件保留给其他页面。
- 揭晓、输入匹配、拖动和点卡面均不计分。只有三个明确的评分按钮提交；先写盘再直接切卡。旧页面按钮、连续点击、跨日按钮不能重复提交。
- 新卡：忘记约1分钟、模糊约5.5–10分钟、首次认识约10分钟后再次回忆。已学卡：忘记约10分钟、模糊约15分钟后巩固。完成学习步骤后按天复习。
- 只在到期时重现未完成卡；等待期间先学其他就绪卡。没有就绪卡时显示下一次时间，前台只安排一次到期刷新，暂停时取消；不再逐秒重建等待页。
- 认识且进入 REVIEW 才获得目标完成量，同一计划每卡最多一次。模糊与忘记不计有效完成；评分次数可以多于卡片数，已处理与完成分别按卡去重。
- 内容可滚动，三按钮等高，置于卡面底部。主题、旋转恢复同卡的输入与揭晓状态，同时恢复管理／学习入口状态，维持正确的底栏及安全间距。
