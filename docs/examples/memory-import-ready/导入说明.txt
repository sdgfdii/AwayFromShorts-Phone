AwayFromShorts 记忆卡片导入说明

手机：底栏“记忆” → “记忆工具” → 添加/选择对应学科 → “卡片” → “批量导入”。
先选清单中的题型，再选择对应 TSV 文件。每个文件只含一个学科、一个题型，无表头。

cards.json 是完整制卡源文件，manifest.json 是导入清单；手机当前应选择 TSV 文件。
无需恢复备份，不会替换整个卡库，也不会改变复习进度、打卡或冻结设置。

共 3 张卡片，跳过 0 张重复卡片。

001-英语单词-input-001.tsv → 学科：英语单词；题型：输入答案；1 张
002-医学-qa-001.tsv → 学科：医学；题型：问答；1 张
003-工科概念-cloze-001.tsv → 学科：工科概念；题型：填空背诵；1 张
