# 高德风格

1.46.0（2129）。入口：**守卫 → 右上角主题设置 → 界面风格 → 高德风格**。同一处选择「原有风格」即可切回。

1.47.0 将图标基础线宽从 1.9 调细至 1.25，并接入[全局瑞士风格排版](SWISS-LAYOUT.md)。

用户特别指出，主要看中高德图标的简洁感。因此重点是统一图标语言：圆角线条、清楚的轮廓、适量留白；底栏未选中使用轮廓图标，选中时使用主题色和适量填充。功能区取消彩色圆形底、渐变和多余装饰，使用目标、历史、统计等各自有含义的线条图形。

配套界面使用浅灰页面、白色分组面板、淡蓝页眉和灰色底栏选中块。五个底栏功能和操作保持原有含义。新风格的主色默认是蓝色，与原有风格的主题色分别保存；字体、文字缩放、深浅色、纯黑、动画和玻璃档位继续使用现有主题设置。打卡卡片的独立字体、背景与禁忌卡的黑色语义继续保留。

## 观察来源

本次通过 REA 6.7.0 的 `capture-adb-screen` 观察用户手机安装的高德地图 `com.autonavi.minimap`，版本 `17.02.0.1541`（170100），参考首页底栏、我的和设置页面。操作使用 ADB；REA 提供截图证据。未将启动广告作为界面参考。

原始证据位于 `.codex-fix/amap-style/reference-*`。参考截图包含手机的实际账户和地图内容，只作为本地观察资料；交付截图使用 AwayFromShorts 页面。

图标在 `AmapStyle.java` 中独立绘制；没有复制高德的品牌图形、账户资料或地图资源，也不依赖地图 SDK。

## 实现

- `AppearanceConfig.skin`：`classic` / `amap`，旧设置默认保持 `classic`。
- `amapSeed`：新风格独立主题色；切换风格不会覆盖旧的 `seed`。
- `AppearancePalette`：分别生成新风格的浅色、深色和纯黑颜色。
- `Ui`、`AmapStyle`：分组面板、功能图标和页面底色。
- `FloatingNav`：统一线条图标、蓝色选中态及灰色选中块，新风格不使用按住时放大的镜片形变。
- `ThemeActivity`：两种风格的预览和持久切换。

原有学习、打卡和冻结数据格式未作调整。记忆复习仍为独立模块。

离线检查包含 30 项 Appearance 断言，覆盖旧配置迁移、风格切换、两套主色保存、深浅色、纯黑和系统主题色；其余模块的回归结果见 `.codex-fix/amap-style/tests.log`。
