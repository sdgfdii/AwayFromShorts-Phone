# 部署与日常使用

## Windows 首次部署

使用完整 Windows ZIP 并解压到普通目录，双击“开始安装.cmd”。包内自带 ADB，无需安装 Java、Python、Git 或 Android Studio。手机需开启 USB 调试、允许电脑调试；部分厂商还需要 USB 驱动和允许 USB 安装。

向导按“识别设备 → 检查条件 → 安装／升级 → 授权与运行验证”执行。多设备时按型号、USB／无线连接和序列号选择，避免安装错设备。首次授权需阅读恢复说明并勾选确认；只检查不会安装或修改手机。操作中不强制关闭进程，失败原因和原始输出可保存为本地诊断日志，不自动上传。

设备所有者通常要求没有账号、分身、多用户或其他管理者。工具遇到不满足条件时明确停止，不自动删除账号、用户、应用数据或恢复出厂。涉及个人资料的处理必须由设备使用者自行备份并决定。

## 日常升级

已安装同签名应用并取得授权的设备走保留数据升级，保留原管理授权与配置，不重复做首次授权。签名不兼容或版本过旧时明确报错，工具不会卸载原应用来绕过。开发签名包与正式签名包不可互相覆盖；选择与原安装同签名的包。

源代码用户仍可使用 `deploy.ps1 -Serial ... -Adb ... -Apk ...`；原命令行入口保留。`-CheckOnly` 只检查，自动化首次授权必须显式 `-AcceptDeviceOwner`。正式构建由仓库外私有签名配置完成；私钥和密码不进入 ZIP。

## 手机操作

- 守卫 → 部署与权限检查：随时查看部署状态，缺少使用情况权限时可直接跳到系统授权；正常时可进入系统应用设置。
- 冻结页：时段与额度就地展示，长按可拖动。点击任意应用直接进入同一详情面板，查看原因、安排冻结时段、编辑额度、查看断网状态或加入／移出断网名单。
- 移动、移出、减少额度和修改断网名单仍遵守原有冻结状态、收束时段、调整时段与纠错期限制，界面简化不绕过限制。
- 卡片、字体、打卡外观与同步：守卫 → 卡管理 → 打卡设置。同步是可选的，离线学习与冻结不需要同步账号。
- 草稿与滚动位置继续保留；后台检查时先显示“正在检查状态”，不以未知状态冒充可使用或已冻结。

## 恢复管理

完整包带同签名维护 APK 和“恢复管理.cmd”。先备份需要保留的数据，按恢复工具说明确认 RECOVER，才解除管理与冻结。默认保留应用数据；明确选择卸载才删除应用数据。维护 APK 的版本号高于同批主包，恢复后若要重新使用，应安装版本号更高的同签名主包。不要把维护 APK 当日常主程序。

## 性能与兼容

冻结页应用磁贴按可见范围创建和复用，离屏清除图片引用；拖动时保护源磁贴，移动后只替换受影响区域。耗时的冻结状态计算和应用暂停状态查询在后台完成，界面读取结果快照。五个主页面暂保留现有 Activity 架构；是否合并以同机帧耗时测量为依据，不承诺所有设备所有场景绝对零卡顿。
